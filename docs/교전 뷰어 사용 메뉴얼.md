## 페이지 3 — 실행 시 나오는 화면

**화면 중앙 캡션(노란색):** 실행시 나오는 화면

**스크린샷 서술:** DogFightViewer(언리얼 기반) 실행 직후의 전체 UI. 검은 배경에 은색 F-16 전투기 2대가 중앙에 마주 보듯 배치되어 있고, 각종 HUD/조종값 오버레이가 표시됨. 화면 내 텍스트·수치를 위치별로 그대로 전사하면:

**상단 HP 바:**
- 좌측: 파란색 체력 바, 아래 라벨 **BlueHpText**, 우측 끝에 **Lost**
- 중앙 상단: 초록색 숫자 **200**
- 우측: 주황색 체력 바, 좌측에 **Lost**, 아래 라벨(빨강) **RedHpText**
- HP 바 아래 중앙: 파란 **23.7** / 빨간 **23.7**

**좌측 패널 — Speed(m/s) :** (십자형 게이지 + 세로 속도 바)
- RollCMD : 0.0
- PitchCMD : 0.0
- RudderCMD : 0.0
- ThrottleCMD : 1.0

**우측 패널 — Speed(m/s) :** (좌측과 동일한 십자형 게이지 + 세로 속도 바)
- RollCMD : 0.0
- PitchCMD : 0.0
- RudderCMD : 0.0
- ThrottleCMD : 1.0

**중앙 기체 오버레이(초록 텍스트):**
- Distance : m
- (파란 기체 쪽) LOS : 0.0 · OBFM_Time : 0.0
- (빨간 기체 쪽) LOS : 0.0 · OBFM_Time : 0.0
- 파란 기체에는 파란색 조준 레티클, 빨간 기체에는 빨간색 조준 레티클

**하단 컨트롤 영역:**
- 시나리오 버튼: `2000ft` `2500ft` `3000ft` / `HABFM`
- Speed(m/s) 입력: `200.0`
- Alt(ft) 입력: `15000.0`
- Port : `9999` · `OpenServer` 버튼 · **Server Off** 상태 표시
- `Start` 버튼 (하단 중앙, 넓은 버튼)
- 우측 하단: **ShowVP** (체크박스) · `Stop_Simulation` 버튼
- 최하단에 작은 로그 텍스트: `36888 스레드가 종료되었습니다(코드: 0 (0x0)).`

## 페이지 4 — UI 요소 설명 ①

페이지 3과 동일한 실행 화면 위에 색상 박스와 라벨로 UI 영역을 설명한 주석 이미지.

- 우측 상단 **X** 버튼(노란 박스 강조) → 라벨(노랑): **종료 버튼**
- 하단 좌측 시나리오 버튼 묶음 `2000ft` `2500ft` `3000ft` `HABFM` (초록 박스 강조) → 라벨(초록): **시나리오 설정 버튼**
- 하단 중앙 `Speed(m/s) 200.0` · `Alt(ft) 15000.0` (하늘색 박스 강조) → 라벨(하늘색): **속력 및 고도 설정**

---

## 페이지 5 — UI 요소 설명 ②

동일 실행 화면 주석 이미지.

- `Port : 9999` · `OpenServer` (초록 박스 강조) → 라벨(초록): **포트 번호 설명 및 서버 오픈 버튼**
- `Start` 버튼 (하늘색 박스 강조) → 라벨(하늘색): **시나리오 시작 버튼**

---

## 페이지 6 — UI 요소 설명 ③

동일 실행 화면 주석 이미지.

- 좌측 Speed(m/s) 패널(RollCMD/PitchCMD/RudderCMD/ThrottleCMD 게이지, 초록 박스 강조) → 라벨(연두): **Blue Plane의 현재 조종값 정보**
- 우측 Speed(m/s) 패널(동일 게이지, 하늘색 박스 강조) → 라벨(하늘색): **Red Plane 조종값 정보**

---

## 페이지 7 — 기본 조작법

**기본 조작법**

- 숫자 키 1 : Blue Plane으로 카메라 고정
- 숫자 키 2 : Red Plane으로 카메라 고정
- 숫자 키 3 : 현재 고정중인 Plane을 기준으로 시점 변경(1인칭 <-> 3인칭)
- 숫자 키 4 : 현재 고정중인 Plane의 위치에서 적기 Plane을 락온
- 숫자 키 5 : 두 Plane의 중심에 카메라가 고정, 두 Plane간 거리에 따라 카메라 거리 자동 조절

- 3인칭 시점에서 카메라 회전 : 마우스 아무 버튼이나 누른 상태에서 마우스 포인터 이동
- 카메라 거리 조절 : 마우스 휠
